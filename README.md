# 水滴里的世界

独立、无登录的移动端视觉实验：

- 首页：铅笔线稿 → 真实彩色世界
- daynight/：黑夜 → 白天
- snow/：蓝调冬季 → 明亮夏季，小圆水滴揭示同位置的另一季

拖动水滴改变观察位置，按压局部形变，松手弹簧回位；双击流动扩张到全屏，再双击返回。页面不放导航、设置或说明文字。

由生成式图像构成同构图的线稿、白天和黑夜图层，所有素材随站点本地提供。生成式配图不承诺物件轮廓逐像素完全重合。照片及图层为此实验生成。

单个全屏 WebGL Canvas，圆角 SDF、水滴速度形变、局部按压、连续折射、色散和局部高光。真实修改纹理采样坐标，不用 blur 卡片冒充。低配设备保留二维揭示降级。390×844 为主要设计尺寸，支持横屏、后台恢复及 reduced-motion。

## 本地运行

需要 Python 3。无运行时第三方依赖、无后端、无 API key。

    python3 -m http.server 4174

打开 http://localhost:4174 。也可运行 npm start。

本项目只包含视觉实验，不包含私人记录、聊天内容或其他应用数据，不要求访客登录。没有分析追踪或外部资源请求。

## 部署

源码在独立的 waterdrop-preview 分支，不修改仓库 main。运行 sh build.sh 将公开网页复制到 public/；静态托管只发布 public/。GitHub Pages 尚未启用；Render 可从该分支构建。所有路径相对引用，支持项目子路径。

## 蓝调雪地

snow/index.html 是新生成的松林木屋雪地：外层保留第一张蓝调雪景，水滴内是以该图编辑生成的同构图夏季。390×844 下水滴直径约 125px（原约 207px），静止为圆形，保留按压、拉扯、松手回弹与双击扩张。

冬季与夏季图片为此次原创生成，未直接使用参考截图。雪地版降低了折射强度与色散，以保留更清透的雪色；旧版默认参数不变。

## 满屏松林四季版

snow/ 当前使用新生成的无黑边竖图：冬季蓝调松林、秋千和暖灯小树；夏季同构图草甸、石径和松林。图片以 quality 92 WebP 本地提供，保留干净天空与雪面。小圆水滴与真实折射交互保持不变。

## 林荫路凝水版

snow/ 当前是按用户林荫路参考生成的夏冬场景（同视角，非像素级配准）。雪夜外层，夏季藏在玻璃后。20 颗锚定凝水组成约六组不规则湿斑和少量小珠，主水滴直径约90px。统一屏幕坐标的连续凸透镜采样；解析平滑并集构成水颈和无缝法线，拉开即分离，锚定水珠不会消失。按压和速度影响主水滴形变；双击仍可展开夏季并返回。

这是满足“融合后小水珠仍留下”的表面张力视觉近似，并非质量守恒的流体求解。没有引入图片噪点或全圈白边。无 WebGL 时保留多珠揭示与拖动交互，降级不模拟折射。静态锚点放在 condensation-layout.js，光学在 condensation.frag。运行 tests/condensation-check.mjs 验证真实触控融合与分离、回弹、转场、尺寸变化、上下文恢复与降级。未测 iPhone 真机帧率。

## 当前版本：只保留主水滴

snow/ 已移除所有静态小水珠和水膜，保留林荫路雪夜与夏季图、约90px主水滴的凸透镜折射、按压、拖动回弹与双击切换。当前使用 droplet.frag，原凝水实验文件保留供历史版本参考。验证入口为 tests/snow-check.mjs。

## 另一条时间线

timeline/ 是独立的新视觉实验，不替换 snow/。打开先见冷蓝雨夜荒屋，单颗约90px水滴起始正对一朵珊瑚色大丽花。拖动时持续凸透镜采样暖阳花房，按压变形、松手回弹。双击先收紧约22%，再以不规则液态前沿展开，最后轻微余波停稳；再次双击返回。无导航、设置、说明或自动播放的转场。

两张低噪点图片为本次生成并编辑配对，窗框、桌子、花瓶和书保持同构图；生成图不保证逐像素完全配准。约0.78MB WebP素材随项目提供，无外部图片请求。timeline.js 与 timeline.frag 独立，原视觉实验不受影响。支持旋转、上下文恢复、减少动态效果、键盘操作及无WebGL二维降级。

启动方式同前：npm start，访问 /timeline/。验证命令 node tests/timeline-check.mjs；在390×844实测模拟触控、初始花朵/外部冷色、收紧-展开-余波、往返、多个尺寸、WebGL恢复、键盘及降级。测试使用Chromium软件GPU，尚未测iPhone真机帧率。这里仍为视觉实验，不含完整PWA。

## 湖里的秘密（当前版本）

lake/ 使用用户提供的雪山湖面 JPEG，文件按原始字节直接复制，不生成、不修图、不调色。全屏按 cover 显示，手机会裁掉少量左右边缘；横屏自动把视线移向湖面，保证纸条与彩蛋可探索。只保留一颗约90px水滴，整个表面通过WebGL凸透镜重采样同一照片。

水滴内的独立透明纹理藏着“你看，山也在水里做梦。”、一弯月亮和一只纸船。秘密定位在照片的倒影区域，屏外不显示，和照片共享坐标与折射。拖动并短暂停留会触发微弱反光反馈，三项发现存入localStorage（存储不可用时仍能玩）。双击展开倒影秘密，再双击收回。无参数、导航或说明文字。

lake.js / lake.frag 是独立实验，不替换旧版。访问 /lake/，验证 node tests/lake-check.mjs，覆盖真实触控发现、实际月亮显现、按压回弹、转场、旋转尺寸、上下文恢复、发现记录刷新保存、键盘、减少动态效果和无WebGL降级。尚未实测iPhone GPU帧率；页面为视觉实验，未添加完整PWA。

湖景清晰度修正：原照片改由浏览器原生背景显示，WebGL透明画布只叠加水滴与秘密；解除旧1.5倍绘制上限，按设备像素比渲染至3倍（受GPU尺寸上限保护）。390×844的3倍屏画布为1170×2532。源图仍是960×1280，满屏裁切放大无法凭空恢复源图之外的细节。

湖景水滴体积修正：由平面径向位移改为球冠高度场，水折射率1.333，Snell折射随表面法线连续改变采样；加入Fresnel反射、随曲面弯曲的软窗反光、高亮点、偏移接触阴影与局部焦散。按压使球冠降低约34%、横向摊开，速度使形体及反光倾斜。仍是屏幕空间光学近似；无WebGL时保留二维揭示，不模拟凸面。原生照片背景与高分屏画布保持不变。

湖景完整构图版：照片改为contain完整显示，剩余区域为纯深蓝，不使用模糊背景或AI放大。水滴、纸条、彩蛋与降级图层共享照片矩形坐标，拖动范围限定在照片内；减弱轮廓高光、边缘暗带与阴影，并在接触边界平滑衰减折射。保留球冠厚度和表面反光。

贴玻璃水滴修正：去除周向亮边，缩短接触阴影并降低球冠高度；静止轮廓略下坠，拖动时后缘收窄形成短尾，保留局部亮点与连续折射。照片完整构图及原生高分辨率显示不变。

可辨识边界修正：恢复细微的接触线，左上短高光、右下暗边，轮廓保持不对称并收窄羽化范围。未恢复圆球造型或整体发白的描边。

水珠材质重新实现：用非球面接触高度场与解析法线代替球冠，扩大接触轮廓的不对称，保留细水边。去除覆盖整个水珠的白色环境反射，保留局部曲面亮点和水折射；缩小纸条字号，减弱放大镜式排版。背景诊断：原JPEG与上传文件SHA-256一致；在390×844、3倍屏模拟下，水滴外与同尺寸原生img直接显示的逐像素差为0。原始文件仍只有960×1280，未复现用户手机端额外模糊；更高照片细节需高清源文件。

圆润轮廓修正：去掉上窄下宽的轮廓扭曲、尾部收窄和三/五瓣扩张扰动。仅保留正定线性拉伸与按压，使水滴在静止、拖动和按压时均保持平滑凸椭圆，材质高度场与细湿边不变。渲染轮廓检查在修复前测得上下肩宽58.5/84.5px，确认收窄过强。
