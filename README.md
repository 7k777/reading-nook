# 水滴里的世界

两个独立、无登录的移动端视觉实验：

- 首页：铅笔线稿 → 真实彩色世界
- daynight/：黑夜 → 白天

拖动水滴改变观察位置，按压局部形变，松手弹簧回位；双击流动扩张到全屏，再双击返回。页面不放导航、设置或说明文字。

由生成式图像构成同构图的线稿、白天和黑夜图层，所有素材随站点本地提供。生成式配图不承诺物件轮廓逐像素完全重合。照片及图层为此实验生成。

单个全屏 WebGL Canvas，圆角 SDF、水滴速度形变、局部按压、连续折射、色散和局部高光。真实修改纹理采样坐标，不用 blur 卡片冒充。低配设备保留二维揭示降级。390×844 为主要设计尺寸，支持横屏、后台恢复及 reduced-motion。

## 本地运行

需要 Python 3。无运行时第三方依赖、无后端、无 API key。

    python3 -m http.server 4174

打开 http://localhost:4174 。也可运行 npm start。

本项目只包含视觉实验，不包含私人记录、聊天内容或其他应用数据，不要求访客登录。没有分析追踪或外部资源请求。

## 部署

GitHub Pages 从独立的 waterdrop-preview 分支根目录发布（不修改仓库 main 分支）；.nojekyll 保证静态资源原样提供。所有路径相对引用，支持项目子路径。

## 验证

tests/check.mjs 使用本环境已有 Playwright/Chromium；其他环境需调整导入和浏览器路径。

已在 390×844 下验证加载、真实触控按压拖动与回弹、双击展开和返回、多个手机尺寸无溢出及控制台错误。iPhone 真机 GPU 帧率仍需实际复核。
